# Rob Run Harvest Timer

A small Windows desktop timer that tells you when your ROB RUN grow-room bushes are ready to harvest again.
Unofficial fan tool - not affiliated with the ROB RUN developer. It never touches the game.

## Using it
1. Tick the upgrades installed on each grow table.
2. Press **Harvested - start timer** the moment you harvest.
3. A sound plays and the timer shows **READY!** when the bush has regrown.

Use **+ Add timer** for tables with different upgrades. Each timer has its own name, upgrades and countdown.

**Grow time = 60 min x (1 - sum of upgrade %)** (measured in game, 2026-11-16):
Fan -12%, Water Pump -14%, UV Lamp -24%.
Fan + Pump = 44.4 min. All three = 30 min (UV Lamp value not yet verified in game; editable in Settings).

## Settings
- **Skin**: Classic, Dark, Forest, Ocean, Synthwave, Paper, plus four design-pass skins that change how the countdown is drawn: **Modern** (flat, thin numerals), **Rob Run** (hazard-plate readout, flashes police red/blue when ready), **Futuristic** (seven-segment LED readout), **Flip Clock** (split-flap cards on walnut and brass). Modern also has rounded corners. Every skin also has a progress bar.
- **Clock only** mode (title-bar ▭ button or bottom bar; double-click the clock to go back): just the countdowns, small enough to park in a screen corner.
- Resizable: drag the ◢ in the bottom-right corner; the countdowns scale with the window.
- 12-hour or 24-hour clock, seconds on or off.
- Base time and the percentage each upgrade cuts.
- Default upgrades for new timers.
- Custom finish sound (.wav, .mp3, .wma), always-on-top, slim title bar.

Your data is saved in `%APPDATA%\RobRunTimer\state.json` (survives updates; delete the folder to reset).

## Run from source
Needs Python 3.10+ with tkinter (included in the normal python.org installer). No other packages.
```
pythonw rob_run_timer.py          # GUI
python rob_run_timer.py status    # CLI: start | ready | set | add | remove | status
```

## Build the .exe
```
powershell -ExecutionPolicy Bypass -File build.ps1
```
Produces `dist\RobRunTimer.exe` (single file, ~10 MB, no Python needed). The icon is generated by
`tools\make_icon.py` (needs Pillow) and committed as `assets\icon.ico`.

Unsigned builds may show a Windows SmartScreen warning ("More info" > "Run anyway").

## New in 1.1

- **Alerts**: Windows notification and taskbar flash when a timer is ready, an early warning (default 2 min before), and an optional sound per timer.
- **Global hotkeys** (work while the game has focus; editable in Settings): `Ctrl+Alt+H` start next ready timer, `Ctrl+Alt+A` start all ready timers, `Ctrl+Alt+M` clock-only view, `Ctrl+Alt+C` click-through.
- **Harvest all** button, **opacity** slider, click-through clock-only view, and **Start with Windows**.
- Window position and size are remembered; the Modern skin now has truly rounded window corners.
- **History / calibrate** (Settings): compares logged cycles with the formula and can correct an unverified upgrade's percentage (UV Lamp).
- Checks GitHub for a newer release at start-up (can be turned off).
